# Hand-painted animation acceptance checklist

- [ ] Scene is authored from the user's story rather than copying the baked sample as the result.
- [ ] Composition and supporting files stay in the hidden project composition directory.
- [ ] Output is a real H.264 MP4: 5 seconds, 1920×1080, 16:9, 24 fps, no audio stream.
- [ ] Media task has completed successfully; failed capture or a placeholder is never reported as success.
- [ ] Final MP4 opens in the existing viewer and can be downloaded.
- [ ] The bundled example has a real poster and playable sample in both Home's Video rail and Community → More → Video.
- [ ] MIT license, pinned upstream commit and attribution remain present.
- [ ] The default character and preview do not use third-party mascot artwork or reference sheets.
- [ ] Separate dependency licenses and the p5 corresponding source archive ship with the renderer.
